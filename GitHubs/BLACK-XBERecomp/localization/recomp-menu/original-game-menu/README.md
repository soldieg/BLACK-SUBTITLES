# Original game menu catalog mirrors

These files are byte-for-byte copies of the available canonical catalogs in [`Localization/Menu/`](../../../../Localization/Menu/): `en-US`, `pt-BR`, `es`, `fr`, `de`, `it`, and `id`. They are included here to make the full menu data visible beside the BLACK-XBERecomp-specific menu translations. Do not edit this copy independently; update the canonical catalog first and then refresh the mirror.

There is no Russian file because the original Russian `MainUK.bin` glyph mapping has not been verified. The separate `ru.jsonl` in the parent directory covers Recomp-specific phrases only.
