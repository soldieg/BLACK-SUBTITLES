# Original game menu catalog mirrors

These files are byte-for-byte copies of the available canonical catalogs in [`Localization/Menu/`](../../../../Localization/Menu/): `en-US`, `pt-BR`, `es`, `fr`, `de`, `it`, and `id`. They are included here to make the full menu data visible beside the BLACK-XBERecomp-specific menu translations. Do not edit these mirrors independently; update the canonical catalog first and then refresh the mirror.

`ru.jsonl` is a partial, readable Russian review of original menu entries keyed by the same stable IDs. It records translations supplied and checked in [Issue #17](https://github.com/soldieg/BLACK-SUBTITLES/issues/17) where they clarify or correct the byte-preserving values in the combined Russian catalog. It is not a complete decoded `MainUK.bin`, does not replace the source bank, and is not yet a runtime-loaded catalog. Unchanged suggestions were checked against the existing Russian text and were left as they were. The separate `ru.jsonl` in the parent directory contains Recomp-specific phrases.
