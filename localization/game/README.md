# In-game menu text catalogs

These UTF-8 JSONL files export the 1,724 keyed string records from the game's `MainUS` menu/text bank. Each row preserves its record index and stable hexadecimal ID alongside the text. `en-US.jsonl` is the English source, and `pt-BR`, `es`, `fr`, `de`, `it`, and `id` are localized catalogs. `proper-name-invariants.jsonl` lists canonical names used during review.

The catalogs are editable source data. They are not the game's binary bank and do not include fonts or other game assets. Preserve IDs and ordering when converting them for a tool or game build. Editorial review is not the same as native-speaker or in-game-context validation.

For Indonesian builds, the standard BLACK `Small.bin` and `Big.bin` font assets are required by the supplied setup. They are byte-identical to the fonts in the base game, so this repository does not redistribute them. From the repository root, prepare a local package from your own game installation with `.\tools\prepare-indonesian-fonts.ps1 -GameRoot "C:\path\to\BLACK\game"`. The script validates both files by size and SHA-256 and writes them under `dist/indonesian-support/language/fonts/`; copy that `language` folder into your game root. The Indonesian `MainUS.bin` is not generated by this script.
