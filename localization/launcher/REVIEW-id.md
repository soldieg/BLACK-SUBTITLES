# Indonesian launcher catalog review

`id.jsonl` contains 292 keyed launcher strings translated from the English entries in `en-pt-BR.jsonl`.

An AI editorial pass compared the translations with every English source entry. It found and corrected a text-to-ID alignment error in IDs 0139–0146, literal newline escapes, several control-name ambiguities, and wording issues. The IDs and source line-break counts now match. The translation remains an AI-reviewed draft and requires review by a native Indonesian speaker before release.

This catalog is source text only. It is not a compiled launcher or executable.
