# Launcher interface catalogs

These UTF-8 JSONL files contain 292 keyed launcher strings. `en-pt-BR.jsonl` holds the English and Brazilian Portuguese source entries; `es.jsonl`, `fr.jsonl`, `de.jsonl`, `it.jsonl`, and `id.jsonl` provide the other locale catalogs. Each locale file retains the shared keys so launchers can select the language without changing the source IDs.

This is text source data only, not a compiled launcher or application. The Indonesian catalog received an AI editorial pass; native-speaker review remains pending. See `REVIEW-id.md`. Translation/editorial review does not imply native-speaker review.
