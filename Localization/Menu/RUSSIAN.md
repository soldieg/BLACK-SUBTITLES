# Russian menu source status

The supplied Russian `MainUK.bin` has not been decoded into a verified text catalog, so no original Russian menu catalog is published under `Localization/Menu/`. Do not treat the Russian Recomp menu file as a replacement for the original game menu: it only covers the additional Recomp UI phrases.

Russian `Big.bin` and `Small.bin` runtime font files are present under `Localization/Fonts/runtime/ru/language/fonts/`. The Russian cutscene subtitle drafts are under `Subtitles/ru/`; their review status is described in that locale README. The original Russian bank and its glyph mapping remain source material for future verification.
