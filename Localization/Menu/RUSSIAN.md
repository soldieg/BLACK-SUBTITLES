# Russian menu source status

The supplied Russian `MainUK.bin` has not been decoded into a complete verified Unicode text catalog. Its 1,724 menu records are included in `GitHubs/BLACK-XBERecomp/localization/recomp-menu/ru.jsonl` as byte-preserving game-glyph text, alongside the 93 Recomp UI strings. A partial Russian review of Issue #17 suggestions, keyed by stable original-menu IDs, is in `GitHubs/BLACK-XBERecomp/localization/recomp-menu/original-game-menu/ru.jsonl`; it only captures entries whose wording was clarified or corrected. This partial file is not a full bank decode and is not runtime-loaded. The Russian bank’s mapping still needs verification before treating all of it as readable Russian prose.

Russian `Big.bin` and `Small.bin` runtime font files are present under `Localization/Fonts/runtime/ru/language/fonts/`. The Russian cutscene subtitle drafts are under `Subtitles/ru/`; their review status is described in that locale README. The original Russian bank and its glyph mapping remain source material for future verification.
