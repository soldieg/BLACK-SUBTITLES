# Indonesian game menu catalog

`id.jsonl` contains the 1,724 text records exported from the user-provided Indonesian `MainUS.bin`. The original archive copies `indonesia language.rar` and `indonesia language (1).rar` were byte-identical (SHA-256: `0f6d81a3fc54a0d97a094765c8ebbf6f20bb5efe34aeb91de0d80b6876a2256b`). The extracted `MainUS.bin` SHA-256 is `eac02a88e4fff6590dfd98151efcea2aa36cc697d03292208efc23ce6c0e8186`.

The exporter preserves the game string IDs and record order. All 1,724 IDs and their order match the English `en-US.jsonl` catalog; the source bank has 776 indexed records. Each row is marked `provided-indonesian-bank-unreviewed`: this records its source, not a completed editorial or native-speaker review.

The original binary language bank is not distributed, but the `Small.bin` and `Big.bin` runtime font dependencies are included under [`../Fonts/runtime/id/language/fonts/`](../Fonts/runtime/id/language/fonts/). Their expected sizes and hashes are recorded in [`../Fonts/id-font-dependencies.json`](../Fonts/id-font-dependencies.json). The preparation helper can also compare them against files from a local game installation. Indonesian cutscene subtitles and launcher strings are provided separately as AI-reviewed drafts, with native-speaker review still pending; see [`../../Subtitles/id/README.md`](../../Subtitles/id/README.md) and [`../../Launcher/REVIEW-id.md`](../../Launcher/REVIEW-id.md). There is no Indonesian gameplay voice-caption catalog in this snapshot.
