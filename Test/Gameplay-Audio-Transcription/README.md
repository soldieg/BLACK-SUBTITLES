# Gameplay audio transcription research

This directory contains analysis candidates, not synchronized subtitles or runtime-ready captions. The detailed set has six locales with 3,591 rows per locale. Audio confirmation and native-speaker review are still pending as recorded by the row-level status fields.

- `large-v3-review-20261011/`: current detailed review set and audit artifacts.
- `legacy-candidates/`: earlier 3,196-row catalogs preserved for comparison.

No extracted audio is included. PT-BR is retained for research but excluded from the downloadable locale package in the manifest.
